# TezRason — веб-платформа для автоматизации заказов и доставки еды

Проект по специализации (Лоиҳаи тахассусӣ). Платформа объединяет клиентов, заведения общественного
питания, курьеров и администратора платформы. Интерфейс поддерживает русский и таджикский языки.

| Часть | Технологии |
|---|---|
| Серверная часть | ASP.NET Core 8 Web API (C#), Entity Framework Core 8, JWT |
| База данных | PostgreSQL 16 (15 таблиц, `database/schema.sql`) |
| Клиентская часть | Angular 20, PrimeNG 20, TypeScript |

## Структура репозитория

```
TezRason/
├── backend/TezRason.Api/      серверная часть (REST API)
│   ├── Domain/                сущности, роли, конечный автомат статусов заказа
│   ├── Data/                  слой данных: EF Core (PostgreSQL) и демо-хранилище в памяти, начальные данные
│   ├── Auth/                  выпуск/проверка JWT, обработчик схемы Bearer
│   ├── Services/              бизнес-логика модулей (заказы, меню, статистика, администрирование)
│   ├── Contracts/             DTO — формат запросов и ответов API
│   ├── Controllers/           REST-контроллеры
│   └── Program.cs             точка входа, внедрение зависимостей
├── frontend/                  клиентская часть (Angular + PrimeNG)
│   └── src/app/{core,layout,pages}
├── database/schema.sql        SQL-скрипт схемы БД
├── tests/                     сквозные тесты API и интерфейса
└── docker-compose.yml         запуск PostgreSQL + API в контейнерах
```

## Быстрый запуск (демо-режим, без PostgreSQL)

Требуется: .NET SDK 8 и Node.js 20+.

```bash
# 1. Собрать клиентскую часть в папку wwwroot сервера
cd frontend
npm install
npm run build:api

# 2. Запустить сервер с хранилищем в памяти
cd ../backend/TezRason.Api
dotnet run --Database:Provider=InMemory --urls http://localhost:5080
```

Открыть http://localhost:5080. Данные демо-режима сбрасываются при перезапуске.

## Запуск с PostgreSQL

1. Создать базу `tezrason` (или запустить `docker compose up -d db`).
2. Проверить строку подключения `ConnectionStrings:Default` в `backend/TezRason.Api/appsettings.json`.
3. Запустить `dotnet run --urls http://localhost:5080`. При первом запуске EF Core создаст таблицы
   и заполнит их демонстрационными данными.

Документация API (Swagger): http://localhost:5080/swagger

Режим разработки клиентской части с горячей перезагрузкой: `cd frontend && npm start` → http://localhost:4200
(запросы `/api` проксируются на `localhost:5080`, см. `proxy.conf.json`).

## Основные сценарии

1. Клиент выбирает заведение, добавляет блюда в корзину и оформляет заказ с оплатой при получении.
2. Администратор заведения принимает заказ → передаёт на кухню → назначает курьера → «Готов к выдаче».
3. Курьер забирает заказ («В пути») и отмечает доставку («Доставлен»).
4. Клиент отслеживает статус в реальном времени (обновление каждые 15 с) и оставляет отзыв.
5. Суперадминистратор модерирует заведения, управляет пользователями и видит статистику платформы.
